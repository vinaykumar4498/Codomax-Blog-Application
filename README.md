# Codomax Blog Application

A full-stack Blog Application developed as part of the Codomax internship.

## Features

- User registration
- User login
- Dashboard
- Create blog
- View blogs
- Backend REST APIs
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## Backend

The backend uses Node.js and Express.js to provide APIs for:

- User registration
- User login
- Creating blogs
- Viewing blogs
